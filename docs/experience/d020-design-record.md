## Bounded first-load handoff and opt-in 3D

`OpeningReadiness.astro` uses Mohanad's identity, graphite, warm white, and a
single controlled amber line. It runs only for a fresh desktop navigation with
no hash, no stored seen flag, and no reduced-motion preference. Session repeats,
history/reload navigation, compact screens, hashes, reduced motion, and static
access bypass the field. No minimum wait or percentage is used. Release follows
the ready event or 1600ms ceiling; pointer, key, wheel, page exit, or media change
releases immediately and cancels the fade. Normal release fades over .3s. Its
40%-width indeterminate line has a 1s ease-in-out cycle and pauses when inactive.

`PassThrough.astro` prepares its module, currently selected hero images, and
explicit Alexandria 700/Manrope 400 loads. `critical-fonts.ts` shares those font
promises with `MotionLoader.astro`. It avoids unrelated document-wide font-set
readiness. The ready event is dispatched even when preparation fails, and the
inline ceiling does not depend on the module arriving. The field does not wait
for Approach or claim to reduce rendering cost.

`InspectionIsland.tsx` gates the launch control on intersection (120px margin),
desktop width, motion preference, and document visibility. The visitor's explicit
`Inspect in 3D` request then probes WebGL2 and dynamically imports the scene.
Artwork stays visible until ready. The preparing button uses aria-busy and
aria-disabled while remaining focusable; readiness moves focus to the range only
if that button still holds focus. The range spans 0 to 100 with a 22% default and
accessible percentage text. Reset returns to 22%; Use artwork returns focus to
the launch action. Failure/context loss supplies a status and retains the image.
Leaving the area, hiding the document, or unsupported media unmounts the scene;
a retained request may reactivate when supported conditions return.

The renderer uses demand frames, DPR 1 to 1.5, low-power preference, and one-frame
environment capture (128 resolution). Material transmission uses 512 resolution
and six samples. Exterior metalness .8/roughness .24 and amber transmission
1/roughness .06/thickness .3/IOR 1.35 remain scene-local. Pointer, range, and scroll
updates invalidate; cleanup removes listeners and the shared invalidation hook.
Those scene values do not become card effects or global palette tokens.

The retained fast local run saw readiness shown at 30.8ms, released at 258.1ms,
and fade complete at 582.9ms. These are navigation-relative observations, not
hosted-load guarantees. The performance record reports the sampled homepage
maximum frame gap changing from 2099.8ms to 33.4ms after automatic renderer
startup was removed. It retains the earlier 50ms Cal.diy outlier and measurement
limits. Explicit renderer launch still has real preparation cost.
